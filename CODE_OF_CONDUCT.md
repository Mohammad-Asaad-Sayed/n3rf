# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1,
in brief:

- **Be respectful.** Critique code, not people. Assume good faith; ask before assuming.
- **Be inclusive.** No harassment, name-calling, or excluded groups; welcome newcomers and
  questions asked in good faith.
- **Be constructive.** Disagree about technical choices with specifics, and accept maintainer
  decisions on scope.
- **Keep private data private.** Respect user data, keys, and systems even in a bug report.

Unacceptable behavior includes trolling, harassment, threats, and any conduct that would violate
this policy or the law where you live.

**Enforcement:** reports of unacceptable behavior go through the same private channel as
[SECURITY.md](./SECURITY.md) — the repository's private security advisory, or the maintainer's
GitHub profile. Maintainers may remove content, close issues, and ban contributors in serious
cases.

This policy applies to all project spaces: the repository, issues, discussions, and community
channels.
